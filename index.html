简明研究路线图

Jared Kaplan　go/roadmap

［先前文档：Research Vision、Ambitious Timeline、April Sketch、May Sketch、RL for Tool Use、Alignment］

最后更新：2021 年 7 月。

长期目标

我们的最高目标是致力于创造安全、有益的 AGI。

作为概念验证，我们正在开发一个通用 AI 助手，它可以与用户对话式交互，创建、编辑和解释软件。这个助手最具雄心的版本可以回答一般性问题、编写函数、识别 bug、设计 API、讨论风格与最佳实践等等——它将具备一位软件工程师同事的全部能力。我们不指望立刻实现这一目标，但这是我们努力的方向。

我们的所有研究项目，都可以视为理解并构建这个 proto-AGI 各个方面的尝试。我们目前认为，这需要具备长时记忆的大型生成式模型，并通过 RL 结合自动化奖励与人类反馈进行微调。

规模化

主要目标：

•
设计能以极高 GPU 利用率和灵活 API 训练超大模型的系统，并能高效采样以用于 RL
•
随着系统效率提升，保持易用性和上手体验——例如，超参数对非专家也很容易设置；我们可以试验高度优化的组件（如 blocksparse attention），即把“黑魔法”封装起来、可与普通组件互换
•
改善我们的安全态势——尤其是针对我们最有价值的资产，如大模型权重
•
降低未来硬件（如 TPU、Trainium 等）的风险，为算力采购做好准备

可解释性

主要目标：

•
围绕大语言模型的基本构件（神经元、注意力头、电路）及其特征统计量来定位我们的认识

•
探索具体能力背后的具体机制，如算术、不同角色间的逼真对话、编程

人类反馈与对齐

主要目标：

•
用人类反馈训练大语言模型，使其总体上乐于助人：提供帮助、回应反馈、提出并回答澄清性问题
•
识别对齐失败，分类并理解简单与困难挑战
•
对齐的规模定律（Scaling Laws for Alignment）

批注 [10] · Amanda Askell · 2021/7/16 17:37
我有点担心，如果我们最终在自然语言上做对齐研究、在代码上做能力研究。这两者之间似乎应该始终保持相当紧密的联系。如果我们在做对齐研究的领域没有提升能力，就会限制我们能测试的对齐程度以及这项工作的用处。这会产生连锁反应，比如对齐研究变成孤岛，因为我们没有及早整合。

其他议题与关联：

•
研究 GAN/判别器训练与测试时计算的规模定律，比较数据多样性与在更窄分布上的最终表现
批注 [11] · Amanda Askell · 2021/7/16 17:40
一个可能的原则：“默认情况下，能力研究与对齐研究在各领域应保持比例，除非我们能给出充分理由说明它们应当分开”。这是好原则还是坏原则？
•
研究人类判断与模型对行为判断、样本质量之间的对应关系，模型“自我评判”的能力，以及与偏见、公平性和社会后果的联系
